# Vamos, BCN — Spanish A1 Learning Game

An interactive, self-contained conversational Spanish course for A1 beginners, themed around everyday life in Barcelona (greeting roommates, ordering at a bar, asking for directions, shopping at La Boqueria, renting a flat).

## How to use

Open `index.html` in any browser — no build step, no server, no dependencies. Progress (XP, streak, completed units) is saved locally in your browser via `localStorage`.

Pair it with `syllabus.html` — an 8-stage A1 syllabus laid out as a metro line, with the grammar the game doesn't teach (ser/estar, present-tense verbs, gustar, ir + a...), a real-life Barcelona task per stage, and a self-assessment checklist.

## What's inside

- 7 units, each set in a real Barcelona scenario, unlocked in sequence
- **Vocabulario** — flip flashcards with Spanish text-to-speech playback
- **Relaciona** — a matching game pairing Spanish words with their English meaning
- **Diálogo** — fill-in-the-blank conversations built from the unit's vocabulary
- **Prueba** — a multiple-choice boss quiz; score 70%+ to unlock the next unit
- A final mixed-review unit pulling vocabulary from the whole course

## Syllabus (`syllabus.html`)

A self-paced, 8-stage study plan, not gated like the game — jump to any stage anytime:

- A grammar note with example sentences for each stage (ser/estar, present-tense verbs, question words, gustar, ir + a + infinitive...)
- A vocabulary theme, and a link to the matching game unit where one exists
- A real-life task to do in Barcelona that week (ask a neighbour for directions, do the weekly shop in Spanish...)
- A "puedo..." self-assessment checklist — checking all three items marks the stage complete and lights it up on the metro-line progress tracker
